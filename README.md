## ✨ What Is This?

Phantom-User is a username generator that actually follows good naming principles. Most generators spit out random garbage like `X4rk_97` — this one builds names that sound real, look purposeful, and are unique enough to be available everywhere.

Every username follows a strict ruleset: pronounceable, no articles, no number substitutions, no repeated letters at word joins, and always main-name-first ordering. The result? Names like **SalmonTree**, **DuskForged**, or **Skybaffy** — not `Th3_D4rk_L0rd`.

## 📐 The Rules

Phantom-User enforces these username principles on every single generation:

| Rule | What It Means |
|------|---------------|
| 🗣️ **Pronounceable** | Every name can be spoken out loud without stumbling |
| 🏗️ **Main Name First** | `DuckRebirthed` over `RebirthDuck` — always |
| 📏 **Longer & Clean** | `SalmonTree` over `S4lmun` — every time |
| 🚫 **No Numbers** | Never appends `123` or swaps `4` for `A` |
| 🚫 **No Underscores** | Clean single-word or PascalCase names only |
| 🚫 **No Articles** | No `The`, `A`, or `An` polluting your name |
| 🔡 **No Repeated Joins** | Won't create `MossShade` where S meets S |
| ✏️ **Easy to Spell** | If someone hears it, they can type it |
| 🎵 **1-2 Syllable Words** | Short, punchy building blocks |
